# Examples

Each example page introduces a complete project and includes the relevant scene source.
The full projects are in `examples/lua/` in the repository.

| Example | What you’ll learn |
| --- | --- |
| [2D Shapes](2d.md) | Create, attach, and animate a built-in circle. |
| [Rectangles and groups](layout.md) | Animate size and position while keeping a shared baseline. |
| [Code](code.md) | Search, highlight, select, and animate edits to source code. |
| [LaTeX](latex.md) | Morph between mathematical expressions and fade to a new formula. |
| [Text](text.md) | Animate changes to text content. |
| [3D primitives and materials](3d.md) | Light, shade, and rotate a built-in 3D primitive. |
| [Canvases and projections](composition.md) | Display a live 3D texture through a 2D projection. |
| [Cameras](camera.md) | Explore 3D framing and animate a 2D camera. |
| [Signals](signals.md) | Derive an object’s position from an independent animated track. |
| [Custom objects](custom-object.md) | Define custom properties, methods, bounds, and 2D or 3D drawing. |
| [Audio](audio.md) | Schedule sound effects with movement and control stereo pan. |
| [Simulation](simulation.md) | Explore fixed-step state, checkpoints, and reproducible randomness. |
| [Procedural drawing](drawing.md) | Draw paths, curves, and gradients in local coordinates. |
| [Shaders](shaders.md) | Animate uniforms in image and mesh shaders. |

Start with the [getting started guide](../guide/start.md) or browse the [API
reference](../api/index.md).
