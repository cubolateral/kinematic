# Lua documentation

The guide is organized around [getting started](guide/start.md), [projects and
scenes](guide/projects.md), [animation](guide/animation.md), and the [generated API
reference](api/index.md). The [examples](examples/index.md) show these concepts in
complete Lua projects.

Implementation notes and benchmarks remain in `docs/internal/`. They describe earlier
revisions and do not replace the current user guide.
